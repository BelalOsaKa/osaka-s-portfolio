Practice project. The charts are drawn from the real Iris dataset, and the example prediction comes from a model trained with the repo's own training code.

01 · What it does

Four measurements in, a species out

On the Overview page you set sepal and petal length and width with four sliders. One click runs the model, which returns the predicted species, its confidence, and a bar chart of every class probability.

The Summary page shows the dataset itself: metric cards, the species distribution, a petal length vs width scatter plot, mean and standard deviation per species, and a preview of the raw data.

02 · How it's built

Train once, load fast

  • 01
    Training (main.py)Loads the Iris dataset from scikit-learn, trains a RandomForestClassifier on it, and saves the model to model.pkl with joblib.
  • 02
    App (app.py)Loads the saved model and the dataset once and caches both, so the app stays fast.
  • 03
    Safety checksIf the model file is missing, or doesn't match the dataset's number of features, the app shows a clear error instead of crashing.
  • 04
    Custom lookIts own CSS for fonts, colours and cards, with a dark green sidebar.
03 · Why it matters

The same pattern, scaled to client data

Swap the Iris data for a business's own spreadsheet and this becomes a working prediction tool a non-technical team can use. That's exactly the service I offer.
